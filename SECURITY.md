# Security Policy

## Reporting a vulnerability

If you discover a security vulnerability in this project, please report it
responsibly. **Do not open a public issue for security problems.**

Instead, contact the maintainer privately through the on-wiki email feature:

- **Italian Wikipedia**: [Email Daimona Eaytoy](https://it.wikipedia.org/wiki/Special:EmailUser/Daimona_Eaytoy)
  (you must be logged in to use this feature).

### Information to include

- A description of the vulnerability.
- Steps to reproduce the issue.
- The potential impact if the vulnerability were exploited.

You will receive a response as soon as possible, and we will coordinate with you
to address the issue in a timely manner.
